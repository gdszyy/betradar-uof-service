# 市场状态 (Market Status)

市场状态是一个重要的概念，Sportradar 为市场提供了不同的状态，如下图所示的状态图：

**状态图说明**

该图例展示了市场状态的流转：

*   市场从 **1x2 Market** 开始，进入 **Active (1)** 状态。
*   **Active (1)** 状态可以转换为 **Suspended (-1)** 或 **Deactivated/Inactive (0)** 状态。
*   **Suspended (-1)** 状态可以回到 **Active (1)** 状态。
*   **Deactivated/Inactive (0)** 状态可以转换为 **Settled (-3)** 或 **Cancelled (-4)** 状态。
*   **Settled (-3)** 状态可以转换为 **Deactivated/Inactive (0)** 状态（例如，在回滚结算时）。
*   **Handed over (-2)** 状态是独立于主要流程的，通常发生在生产者交接时。

---

## 市场状态 ID 详情

当回滚投注结算时，市场状态将变为 **0 (Deactivated)**。但由于某些特定情况（例如，一个进球被审查后最终判定无效），下一个 `odds_change` 消息中可能会将该市场重新包含为 **Active (status=1)**。

下表详细说明了 Betradar 提供的各种市场状态：

| Status ID | Status Text | 描述 (Description) | 额外说明 (Notes) |
| :---: | :--- | :--- | :--- |
| **1** | **Active** | 提供赔率，您可以接受该市场的投注。 | |
| **-1** | **Suspended** | 继续提供赔率，但您不应在短时间内接受该市场的投注（例如，在进球前夕直到进球被观察/确认）。 | |
| **0** | **Deactivated/Inactive** | 不再为该市场提供赔率。市场可以再次变回 **Active** 状态。例如：一个总进球 3.5 的市场在 0.5、1.5 或 2.5 是最平衡的市场时会被停用。然而，如果进球得分，则 3.5 市场可能再次成为最平衡的市场，状态变为 **Active**。发生这种变化的原因有很多，并且经常发生。 | **注意**：从已结算状态回滚的市场可以再次变回 **Active** 状态。例如，如果一个进球正在被审查，最终判定无效。这将导致再次提供例如“第一个进球”的市场。 |
| **-3** | **Settled** | 已为该市场发送投注结算消息，不会再提供进一步的赔率。**然而，需要注意的是，在极少数情况下（错误条件），已结算的市场可能会通过 `bet_cancel` 消息被移至 **Cancelled** 状态。** | |
| **-4** | **Cancelled** | 该市场已被取消。不会再为该市场提供进一步的赔率。**此状态仅在系统已为该特定市场发送取消消息的比赛恢复期间可见。** | |
| **-2** | **Handed over** | **这不是一个真正的市场状态。** 此状态通常在生产者之间的交接期间和有时在恢复期间出现。这是一个生产者发送的信号，用于指定消息将不再发送特定市场的赔率。赔率将从另一个生产者继续提供（并且可能已经开始从新的生产者提供）。当 Live Odds 生产者接管一个市场时，赛前生产者也会发送 **Handed over** 状态。如果您尚未收到 Live Odds 变化，则市场应被暂停，否则该消息可以忽略。如果 Live Odds 变化最终没有出现，则该市场应被停用。 | **注意**：如果在 **Handed over** 市场发生后超过 60 秒没有赔率变化，则应将其视为错误情况。 |
